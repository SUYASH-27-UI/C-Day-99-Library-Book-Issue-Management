# C Day 99 – Library Book Issue Management System

## Description
A menu-driven library management application developed using C structures and file handling.

## Features
- Add new books.
- Display all books.
- Issue available books.
- Return issued books.
- Maintain book availability status.
- Save book records permanently.

## Files
- `library.c` – Main C program.
- `books.txt` – Sample book database.
- `temp.txt` – Temporary file used during updates.

## How to Compile
```bash
gcc library.c -o library
```

## How to Run
Windows:
```bash
library.exe
```

Linux:
```bash
./library
```

## Concepts Used
- Structures
- Functions
- File Handling
- Record Updating
- Temporary Files
- Menu-driven Programming
